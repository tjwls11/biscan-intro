대상 목록

정답표가 있는 대상 2곳으로 탐지율과 오탐률을 측정하고, 공개 취약 웹 2곳으로 저장형 재조회와 다양한 입력 경로에서의 동작 확인

대상 구분 용도 규모
OWASP Benchmark 1.2 정량 평가 정답표 기반 정량 평가 SQLi 504건, XSS 455건
자체 테스트 사이트 정량 평가 PHP, MySQL 게시판 SQLi 8곳, XSS 7곳
DVWA 동작 검증 취약 웹 애플리케이션, 저장형 재조회 등 동작 검증
WackoPicko 동작 검증 취약점 테스트용 웹 환경, 다양한 입력과 공격 경로 검증

자체 테스트 사이트

스캐너 평가용으로 직접 제작한 PHP, MySQL 게시판. 위치가 알려진 취약점과 안전한 코드를 함께 두고 탐지 결과를 정답표와 비교

실행 환경
PHP 8.2 Apache, MySQL 8.0, Docker Compose
SQL Injection
8곳, 파라미터 13개
XSS
7곳, Reflected 2, Stored 4, DOM 1
평가 방식
정답표 기준 탐지, 누락, 오탐 계산

도구 비교

동일한 테스트 대상에 대한 기존 도구와 구현 시스템의 XSS 유형별 탐지 수, 오탐 수 비교

비교 도구
OWASP ZAP, Dalfox, 구현 시스템
비교 항목
반사형, 저장형, DOM 탐지 수와 오탐 수

SQLi 검증 방식별 비교 실험

Benchmark SQLi 504건에 대한 같은 응답을 E0에서 E3까지 단계별로 재판정을 통한 검증 조건 추가에 따른 탐지율과 오탐률 변화 측정

단계 검증 방식
E0단순 응답 비교
E1E0 + 동적 영역 제거, 기준 2회 비교
E2E1 + 대조 입력으로 잡음 측정
E3E2 + 반복 재현 요구
