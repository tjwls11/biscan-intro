배경

2025년 개인정보 유출신고 46% 증가, 유출 원인의 62%가 해킹. 랜섬웨어와 웹 취약점 공격 증가세 연합뉴스, 2026.05.15

소스코드 없이 실행 중인 서비스를 점검하고, 공격 요청에 대한 응답과 동작으로 증거를 확인하기 위해 동적 분석(DAST) 방식 선택

진단 대상은 SQL Injection과 XSS. Injection은 OWASP Top 10:2025 5위 항목이며, 서버 응답 변화와 브라우저 실행 여부라는 서로 다른 방식으로 검증 가능

동작 과정

  1. 01수집Firefox 요청을 ZAP 프록시로 기록, Spider와 Ajax Spider 크롤링
  2. 02정규화범위 밖 요청, 로그아웃과 삭제 같은 위험 URL 제외. 같은 이름의 파라미터도 위치와 순서로 구분해 검사 지점 구성
  3. 03공격 선별입력값 반사 여부와 출력 문맥 분석, 조건에 맞지 않는 공격은 사유와 함께 제외
  4. 04공격 생성검사 지점마다 기준 요청 1회, SQLi 공격 6종, XSS 공격 14종
  5. 05전송ZAP API로 동일 로그인 세션 유지, GET과 HEAD만 재시도, POST 재전송 방지
  6. 06판정공격별 증거 확인, Firefox에서 XSS 실행 확인
  7. 07집계판정 근거, 진행 상태, 실패 사유 저장 후 웹 화면과 PDF 보고서로 출력

XSS
