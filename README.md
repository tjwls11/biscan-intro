# BIScan 소개 페이지

메인: index.html
테스트 대상 상세: target.html
보충 자료: about.html

화이트 배경, Noto Sans KR, 무채색 본문과 조작 요소의 블루그레이 강조색 사용.

사용 흐름은 스크롤에 따라 화면과 설명이 함께 디졸브 전환. 단계 버튼으로 해당 구간 이동. 모바일에서는 세 단계 모두 세로 표시. 화면 클릭으로 확대, Escape로 닫기.
시스템 구조는 요소 선택, 이동, 확대와 축소, 사용자 요청에 따른 흐름 재생 지원.

정적 웹 서버에서 실행. 파일을 직접 열면 SVG 불러오기가 제한되어 기본 구조도 이미지 표시.
